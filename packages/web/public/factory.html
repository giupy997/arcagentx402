Build your own paying agent

Four questions · you get an AI agent that pays for APIs in USDC on Arc, under limits it cannot change · nothing to sign up for

What do you want to build?

Two sides of the same rail. One gives your AI a budget to buy with. The other puts a price on an API you already run.

1. Where will the agent live?

The program you talk to your AI in. The agent plugs into it as a set of tools.

2. How much may it spend?

Pick a starting point, then change any number. These are hard limits: the AI cannot raise them, because it never sees them as something it can edit.

3. Which sites may it pay?

Leave empty to let it pay any site that asks over x402, within the limits above. Or list the only sites you trust, one per line.

4. Network and key file

The agent gets its own new wallet. Its key is created on your machine by the command below, never by this page. Leave the path as it is unless you want the file somewhere else.

Your agent, in words

1. Your API and your wallet

The API stays where it is and as it is. Buyers will call a small server that stands in front of it, and pay you on Arc.

2. The price

Per call, in dollars. Agents buy small things often: a fraction of a cent to a few cents is the usual range. You can price single paths differently later, with the --route option.

3. Network and public address

If you already know the https address buyers will use, write it and the command lists you on the market by itself. If not, leave it empty and add it later from the market page.

Your shop, in words

What this page does not do

It does not create a wallet, see a key, or send anything anywhere: everything above is put together in your browser, and the key is made on your machine by the command you paste. The command is open source: the “by hand” section shows every step it takes. It does not hold your money either. The agent spends from its own small wallet, which you fill, and it can never spend more than what is in it or more than the limits you set.

Want to see a payment first, with no install? Buy one API call from your browser wallet. Every payment made through us is listed on the status page.
